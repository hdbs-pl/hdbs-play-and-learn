PUBLISH FREE
Recommended: GitHub Pages. Create a free GitHub account, make a public repository,
upload all these files, then enable Pages from the main branch.

IMPORTANT AFTER PUBLISHING
Replace https://YOUR-FREE-ADDRESS.example in robots.txt and sitemap.xml with the
actual free website address you receive (for example https://yourname.github.io).

The site can then be submitted to Google Search Console. Google decides when and
whether pages appear in search results; publishing does not guarantee an instant ranking.
